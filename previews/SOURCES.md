# Asset sources

Visual reference images for four MIT-licensed repositories. All files were fetched read-only on 2026-11-01. Filenames were renamed to ASCII.

"Derived" means the file was produced locally from the listed original by cropping, compositing or extracting a frame. The pixels were not repainted. Pixel-art scaling used nearest-neighbor only.

**License caveat.** Each repository's MIT license is listed as declared by that repository. For PixelSRPG-Forge, much of the content appears to be redistributed third-party art. The "Apparent origin" column records what the file names and embedded credits suggest. Verify the upstream terms before redistributing those images beyond reference use.
