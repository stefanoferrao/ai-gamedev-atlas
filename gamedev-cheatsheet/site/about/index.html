About Game Dev Cheat Sheet

Game Dev Cheat Sheet is maintained by Nicolas Zullo. It is a visual reference for people building games, including developers using AI coding tools.

Each concept pairs a plain-language explanation with an interactive example and a prompt you can adapt to your project. The detailed guides add use cases, engine-neutral pseudocode, and common mistakes. The examples teach a technique; they are not a complete engine implementation.

How to use this site

Start with the animation, read the explanation, then compare the example with your own game. Treat suggested timings and distances as starting points to test. Performance improvements should be measured in a representative scene.
